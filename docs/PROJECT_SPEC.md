# Project specification

Hibi (日々), “Small steps, every day.” / “小さな一歩、毎日。”, is a single-user, offline personal life management and growth application. It adapts to evolving routines rather than imposing fixed habits. Android is the only target; the interface is English, currency is IDR, and dates display like 2026年11月26日(木). There is no account or remote authentication.

## Scope and status

Milestone 0 through Milestone 6 are accepted by the owner. **Milestone 7 (Finalization)** is implemented and verified on host (`dart format`, `flutter analyze`, 313 passing tests covering `T-001` through `T-013` plus offline performance benchmark, `integration_test/app_test.dart`, Android debug APK and Android release APK `63.4 MB`), alongside prior physical Android 16 (API 36) verification of live `v12 -> v14 -> v15 -> v16 -> v17` migrations and visual checks on `2510DRA23E`, awaiting final owner acceptance. Optional legacy text import (`R-014`) remains explicitly deferred until separately approved. The habit engine supports eight tracking types, dated configuration, schedules, optional templates and historical counter target correction. History provides filtering, private-by-default redaction, Dynamic Normalized Scoring, recording and score coverage, heatmaps, reports and scheduled-occurrence streaks. Finance provides local integer-IDR wallets with opening balances, income/expense categories, audited transactions, atomic inter-wallet transfers excluded from income/expense, period-scoped expense budgets (rollover disabled by default), period cash-flow/balance reports, and an immutable audit trail. Growth provides optional multi-entry-per-day journal & mood reflections (non-diagnostic, private-by-default), goals with milestones, immutable status history and deduplicated manual/linked progress, restart-safe 25/5/15 Focus/Pomodoro sessions with interruption tracking and idempotent linked habit/goal progress, and opt-in Gamification (versioned immutable XP ledger, `100 × L` levels, deterministic achievements preserving unlock history on invalidation, custom non-moralizing activity attributes, atomic correction reconciliation, and private/opt-out exclusions). More provides optional local App Lock (salted PBKDF2-SHA256 PIN in Android Keystore, BiometricPrompt, resume lock, `FLAG_SECURE` recent-app protection, wipe-based forgotten-PIN reset), permanent trigger-preserving privacy deletion, schedule-aware local reminders with generic private text and inexact Android fallback, AES-GCM-256 encrypted atomic backup/restore with pre-restore snapshots, and private-by-default JSON/CSV/PDF exports. Starter templates are optional; never fabricate real history or user records.

The Japanese PDF font was subsequently bundled and verified on the host; the prior finalization test and build counts predate that change. Current verification status is in PROGRESS.md and HANDOFF.md. Milestone 7 remains active pending final verification and owner acceptance.

The Habit Builder is available from Today and More. Today supports current-day logging, dated lifecycle controls, strictly future version/configuration scheduling and read-only version/audit inspection for all eight configured tracking types (`counter`, `checklist`, `avoidance`, `boolean`, `duration`, `measurement`, `timeOfDay`, `range`), prior-date recovery for eligible counter and checklist records, and read-set-bound historical counter target correction preview/confirmation. Future-start habits show their first configuration for lifecycle management without making them applicable today. An eligible habit can be paused from its initial start date without overwriting the original event; ordinary transitions remain append-only.

## Boundaries

The application must work without internet and use local persistence only. No backend, cloud database, external APIs, Firebase, Supabase, advertising, mandatory authentication, AI analysis, medical diagnosis, religious judgment, or automatic prayer-time or location inference. Rule-based insights must not infer causation. No unauthorized feature or automatic commit, push, publication or release. Future text-record import is optional until separately approved, and requires review and confirmation.

The development Android application ID is `com.example.hibi`, a placeholder requiring owner confirmation before public distribution. Local SQLite is not encrypted by this foundation; device security and future app lock are not equivalent to database encryption. See SECURITY_PRIVACY.md.
